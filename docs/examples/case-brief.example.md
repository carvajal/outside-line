# Case brief — example

This is a sample of the operator-authored brief the `case_brief_lookup`
tool grounds its answers in. Write your own version of this file to
`data/case_brief/brief.md` (gitignored — case material never belongs in
git; on a deployed instance it lives on the persistent volume). All
parties and dates below are fictional.

> **Cache caveat:** the brief is read once per process and cached.
> After editing it, restart the app (or redeploy) to pick up changes.

---
